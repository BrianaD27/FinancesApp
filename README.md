💰 Personal Finance Tracker

A cross-platform mobile app that helps users track income, expenses, and investments while offering real-time budget insights and category-based analytics. Built with performance and usability in mind, the app uses Redis caching and a clean UI to make finance tracking seamless.

🚀 Features
- 📊 Income & Expense Tracking – Log and categorize transactions.
- 💸 Investment Dashboard – Monitor investment growth over time.
- ⚡ Real-Time Insights – Budget summaries and spending analytics.
- 🗂️ Category-Based Reports – Understand where your money goes.
- 🗄️ Redis Caching – Faster queries and optimized performance.
- 📱 Cross-Platform – Runs on both Android and iOS with React Native.

🛠️ Tech Stack
- Frontend: React Native, Figma (UI/UX design)
- Backend: Express.js (Node.js)
- Database: PostgreSQL
- Caching: Redis
- Version Control: GitHub

📦 Installation & Setup

Clone the repository:
```
git clone https://github.com/YourUsername/finance-tracker.git
cd finance-tracker
```

Install dependencies:
```
npm install
```

Start the backend server:
```
cd server
npm start
```

Run the mobile app:
```
npx expo start
```
